NutrientKG: A Food-Health Knowledge Graph for Disease-Aware Recipe Adaptation

Current Version: 1.0 (CKD Instantiation) | Release Date: May 2026 | License: CC-BY 4.0 | DOI: Pending (Zenodo)

Overview

NutrientKG is a food-health knowledge graph providing infrastructure for disease-aware recipe adaptation across chronic disease conditions. This initial version instantiates NutrientKG for Chronic Kidney Disease (CKD), integrating culinary knowledge, nutritional data, validated substitution pairs, and disease staging constraints.

Key Capabilities:

  • Nutritional queries over 467,069 USDA FoodData Central entries
  • Validated substitution recommendations with population-level frequency data
  • Disease-diet constraint checking using KDIGO 2024 guidelines
  • Progression-aware dietary safety verification across CKD stages

Data Sources Integrated

  1. USDA FoodData Central: Nutritional compositions (sodium, potassium, phosphorus, protein)
  2. Recipe1M: 1M+ recipes with ingredient lists
  3. Recipe1MSubs: Validated substitution pairs with frequency data
  4. National Kidney Foundation: 9 clinically verified kidney-friendly recipes
  5. KDIGO 2024: Clinical practice guidelines for CKD dietary management
  6. SNOMED CT: Clinical terminology for disease staging
  7. FoodOn: Food product taxonomy (structural relationships for GNN message passing)

Schema Overview

Core Entity Types

Entity Type Count Description
nutrientkg:Recipe 1,029,568 Recipes with ingredient lists from Recipe1M
nutrientkg:NKFRecipe 9 Subclass of Recipe; dietitian-verified kidney-friendly recipes from NKF
nutrientkg:Ingredient 289,760 matched Food items matched to USDA nutritional profiles
nutrientkg:SubstitutionPair 30,782 Reified substitution pairs with observation frequency counts
nutrientkg:USDA 289,760 Nutritional data nodes storing per-100g clinical nutrient values
nutrientkg:CKDStage 6 Disease stages (1, 2, 3a, 3b, 4, 5) with KDIGO thresholds and SNOMED CT alignment
nutrientkg:RiskProfile 1,009,042 Reified nutrient violation annotations per ingredient per stage

Namespaces

  • Entities: http://nutrientkg.org/entity/   (prefix: nutrientkg:)
  • Properties: http://nutrientkg.org/property/   (prefix: nkgp:)

Key Properties

Recipe / Ingredient:

  • nkgp:has_ingredient: Links recipes to ingredient nodes
  • nkgp:has_amount_grams: Ingredient quantity per recipe occurrence

Nutritional (per 100g, stored on USDA node):

  • nkgp:has_usda_entry: Ingredient → USDA node
  • nkgp:sodium_mg, nkgp:potassium_mg, nkgp:phosphorus_mg, nkgp:protein_g
  • nkgp:phosphorus_source_type: animal / plant / additive / unknown
  • nkgp:fdc_description: FDC description of matched food

Match provenance (stored on ingredient node):

  • nkgp:match_source: Matching layer (alias, fdc_fuzzy, normalised, …)
  • nkgp:match_score: Fuzzy similarity score (75–100)
  • nkgp:confidence_tier: high / medium / low
  • nkgp:canonical_name: Cleaned ingredient name for SPARQL deduplication

Substitution:

  • nkgp:substitutes_for: Direct ingredient-to-ingredient substitution link
  • nkgp:substitution_source, nkgp:substitution_target, nkgp:substitution_frequency: On SubstitutionPair node
  • nkgp:safe_substitute_at_stage_X: Precomputed per-stage safety flags

Disease constraints:

  • nkgp:safe_at: Ingredient passes all active KDIGO rules at given stage
  • nkgp:restricted_at: Ingredient violates at least one rule at given stage
  • nkgp:has_ckd_risk: Ingredient → RiskProfile node
  • nkgp:risk_type, nkgp:at_stage: On RiskProfile node

CKD stage (stored on CKDStage node):

  • owl:sameAs: SNOMED CT concept URI
  • nkgp:sodium_threshold_mg, nkgp:potassium_threshold_mg, nkgp:phosphorus_threshold_mg, nkgp:protein_threshold_g
  • nkgp:stage_order: Integer 1–6 for progression queries
  • nkgp:guideline_source: KDIGO_2024
  • nkgp:progresses_to: Next stage in CKD progression chain

NKF recipe (per serving, stored on NKFRecipe node):

  • nkgp:sodium_per_serving, nkgp:potassium_per_serving, nkgp:phosphorus_per_serving, nkgp:protein_per_serving
  • nkgp:safe_at: CKD stages verified safe by dietitians
  • nkgp:validatedBy: nutrientkg:NationalKidneyFoundation
  • nkgp:hasDietaryLabel: low-sodium, low-potassium, low-phosphorus

KDIGO 2024 Per-Meal Thresholds

Thresholds are derived by dividing KDIGO 2024 daily limits by three meals. Stored as queryable triples on each stage node.

Nutrient Stage 1 Stage 2 Stage 3a Stage 3b Stage 4 Stage 5
Sodium (mg) 767 767 500 500 333 267
Potassium (mg) — — — 667 500 500
Phosphorus - animal/additive (mg) — — — 233 167 167
Phosphorus - plant (mg) — — — — 167 167
Protein (g) — — 19 14 14 9

Dashes indicate nutrient not actively restricted at that stage. Phosphorus restrictions at Stage 3b apply to animal and additive sources only; plant phosphorus is restricted from Stage 4 due to lower bioavailability.

Sample SPARQL Queries

Eight queries organized into three tiers by knowledge requirements. Full query files are available in the sparql/ directory. Load the graph into Blazegraph (java -server -Xmx16g -jar blazegraph.jar) before running.

Tier 1: Culinary Substitution

These queries exploit Recipe1MSubs validated substitution pairs and frequency data. FoodKG cannot answer any Tier 1 query.

Q1: Substitutes for an ingredient ranked by observation frequency

Returns validated substitutes for butter ranked by frequency across 70,520 Recipe1M substitution instances. Results: olive oil (547), margarine (320), coconut oil (156).

PREFIX nutrientkg: <http://nutrientkg.org/entity/>
PREFIX nkgp:       <http://nutrientkg.org/property/>
PREFIX rdf:        <http://www.w3.org/1999/02/22-rdf-syntax-ns#>

SELECT ?sub ?freq WHERE {
  ?pair rdf:type                    nutrientkg:SubstitutionPair .
  ?pair nkgp:substitution_source    nutrientkg:ingredient_butter .
  ?pair nkgp:substitution_target    ?sub .
  ?pair nkgp:substitution_frequency ?freq .
}
ORDER BY DESC(?freq)
LIMIT 15

Q2: Complete nutrient profile for all ingredients in a recipe

Returns sodium, potassium, phosphorus, and protein for every ingredient in a recipe. Demonstrates NutrientKG's expanded USDA coverage across 467,069 FoodData Central entries.

PREFIX nutrientkg: <http://nutrientkg.org/entity/>
PREFIX nkgp:       <http://nutrientkg.org/property/>
PREFIX dc:         <http://purl.org/dc/elements/1.1/>

SELECT ?ing ?sodium ?potassium ?phosphorus ?protein WHERE {
    ?recipe dc:title ?title .
    FILTER(CONTAINS(LCASE(STR(?title)), "chicken stir fry"))
    ?recipe nkgp:has_ingredient ?ing .
    ?ing nkgp:has_usda_entry ?usda .
    ?usda nkgp:sodium_mg     ?sodium .
    ?usda nkgp:potassium_mg  ?potassium .
    ?usda nkgp:phosphorus_mg ?phosphorus .
    ?usda nkgp:protein_g     ?protein .
} LIMIT 20

Q3: Context-specific substitutes filtered by recipe title

Retrieves validated substitutes for a given ingredient that appear in recipes matching a title keyword, enabling context-aware recommendations.

PREFIX nutrientkg: <http://nutrientkg.org/entity/>
PREFIX nkgp:       <http://nutrientkg.org/property/>
PREFIX rdf:        <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX dc:         <http://purl.org/dc/elements/1.1/>

SELECT ?sub_name (SUM(xsd:integer(?freq)) AS ?total_freq) WHERE {
    ?ing nkgp:canonical_name ?name .
    FILTER(LCASE(REPLACE(STR(?name), "_", " ")) = "chicken")
    ?recipe dc:title ?title .
    FILTER(CONTAINS(LCASE(STR(?title)), "stir fry"))
    ?recipe nkgp:has_ingredient ?ing .
    ?pair rdf:type                    nutrientkg:SubstitutionPair .
    ?pair nkgp:substitution_source    ?ing .
    ?pair nkgp:substitution_target    ?sub .
    ?pair nkgp:substitution_frequency ?freq .
    BIND(REPLACE(REPLACE(STR(?sub),
         "http://nutrientkg.org/entity/ingredient_",""),"_"," ")
         AS ?sub_name)
}
GROUP BY ?sub ?sub_name
ORDER BY DESC(SUM(xsd:integer(?freq)))
LIMIT 15

Tier 2: CKD Constraints

These queries require KDIGO staging constraints absent from FoodKG.

Q4: NKF-validated recipes safe for a specific CKD stage

Retrieves NKF kidney-friendly recipes safe for Stage 4, using the nkgp:safe_at property enriched with KDIGO stage annotations. Neither FoodKG nor the original NKF collection supports stage-specific queries.

PREFIX nutrientkg: <http://nutrientkg.org/entity/>
PREFIX nkgp:       <http://nutrientkg.org/property/>
PREFIX rdf:        <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs:       <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?recipe_title ?sodium_per_serving ?potassium_per_serving
       ?phosphorus_per_serving ?protein_per_serving ?dietary_label
WHERE {
    ?recipe rdf:type                    nutrientkg:NKFRecipe .
    ?recipe rdfs:label                  ?recipe_title .
    ?recipe nkgp:safe_at                nutrientkg:stage_5 .
    ?recipe nkgp:sodium_per_serving     ?sodium_per_serving .
    ?recipe nkgp:potassium_per_serving  ?potassium_per_serving .
    ?recipe nkgp:phosphorus_per_serving ?phosphorus_per_serving .
    ?recipe nkgp:protein_per_serving    ?protein_per_serving .
    OPTIONAL { ?recipe nkgp:hasDietaryLabel ?dietary_label }
}
ORDER BY ?phosphorus_per_serving


Q5: Violating ingredients in a recipe at a given stage



Identifies violating ingredients via RiskProfile nodes encoding specific violation types. For chicken stir-fry at Stage 3b returns soy sauce (914 mg sodium vs 500 mg limit), chicken breast (228 mg phosphorus vs 233 mg limit), and chicken broth (343 mg sodium).



PREFIX nutrientkg: <http://nutrientkg.org/entity/>
PREFIX nkgp:       <http://nutrientkg.org/property/>
PREFIX dc:         <http://purl.org/dc/elements/1.1/>

SELECT ?ing ?risk_type WHERE {
    ?recipe dc:title ?title .
    FILTER(CONTAINS(LCASE(STR(?title)), "chicken stir fry"))
    ?recipe nkgp:has_ingredient ?ing .
    ?ing nkgp:has_ckd_risk ?risk .
    ?risk nkgp:at_stage  "stage_3b" .
    ?risk nkgp:risk_type ?risk_type .
}
LIMIT 20




Tier 3: Progression-Aware



These queries require both Recipe1MSubs and KDIGO multi-stage constraints simultaneously. FoodKG cannot answer any Tier 3 query.



Q6: Safe substitutes across disease progression from Stage 3b onward



Uses a MINUS clause to exclude substitutes violating constraints at any stage with stage_order >= 4 (Stage 3b onward). Accesses thresholds directly from CKDStage nodes. Returns turkey (frequency 13) and canned chicken (frequency 5).



PREFIX nutrientkg: <http://nutrientkg.org/entity/>
PREFIX nkgp:       <http://nutrientkg.org/property/>
PREFIX rdf:        <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX xsd:        <http://www.w3.org/2001/XMLSchema#>

SELECT ?sub ?sub_name (COUNT(?pair) AS ?freq) WHERE {
    ?ing nkgp:canonical_name ?name .
    FILTER(LCASE(REPLACE(STR(?name), "_", " ")) = "chicken")
    ?pair rdf:type                 nutrientkg:SubstitutionPair .
    ?pair nkgp:substitution_source ?ing .
    ?pair nkgp:substitution_target ?sub .
    MINUS {
        ?sub nkgp:has_usda_entry      ?usda .
        ?usda nkgp:sodium_mg          ?sodium .
        FILTER(xsd:decimal(?sodium) > 333)
    }
    BIND(REPLACE(REPLACE(STR(?sub),
         "http://nutrientkg.org/entity/ingredient_",""),"_"," ")
         AS ?sub_name)
}
GROUP BY ?sub ?sub_name
ORDER BY DESC(COUNT(?pair))
LIMIT 15



Q7: Substitutes safe at Stage 3b but restricted at Stage 4



Selects ingredients with both safe_at stage_3b and restricted_at stage_4 edges, revealing foods patients must eliminate as disease progresses. Returns squash (frequency 8) which is safe at Stage 3b but violates potassium limits at Stage 4.



PREFIX nutrientkg: <http://nutrientkg.org/entity/>
PREFIX nkgp:       <http://nutrientkg.org/property/>
PREFIX xsd:        <http://www.w3.org/2001/XMLSchema#>

SELECT ?substitute_name ?frequency ?safe_at_4 ?safe_at_5
WHERE {
    ?subNode nkgp:substitution_source    nutrientkg:ingredient_chicken .
    ?subNode nkgp:substitution_target    ?target .
    ?subNode nkgp:substitution_frequency ?frequency .

    # Only keep substitutes that are safe at stage 3b
    nutrientkg:ingredient_chicken nkgp:safe_substitute_at_stage_3b ?target .

    BIND(IF(EXISTS {
        nutrientkg:ingredient_chicken nkgp:safe_substitute_at_stage_4 ?target
    }, "safe", "UNSAFE") AS ?safe_at_4)

    BIND(IF(EXISTS {
        nutrientkg:ingredient_chicken nkgp:safe_substitute_at_stage_5 ?target
    }, "safe", "UNSAFE") AS ?safe_at_5)

    BIND(REPLACE(REPLACE(STR(?target),
         "http://nutrientkg.org/entity/ingredient_",""),"_"," ")
         AS ?substitute_name)
}
ORDER BY DESC(xsd:decimal(?frequency))
LIMIT 10



Q8: Cumulative nutrient burden for ingredient combinations



Sums nutrient values across two ingredients using SPARQL BIND and filters combinations where totals satisfy Stage 3b thresholds. For chicken and cheese at Stage 3b returns 0 valid combinations, demonstrating meal planning support that accounts for cumulative nutrient loads rather than evaluating ingredients in isolation.



PREFIX nutrientkg: <http://nutrientkg.org/entity/>
PREFIX nkgp:       <http://nutrientkg.org/property/>
PREFIX xsd:        <http://www.w3.org/2001/XMLSchema#>

SELECT ?ing1_name ?ing2_name ?total_sodium ?total_phosphorus ?total_potassium
WHERE {
    VALUES ?ing1 { nutrientkg:ingredient_chicken }
    VALUES ?ing2 {
        nutrientkg:ingredient_._cream_cheese
        nutrientkg:ingredient_c._cream_cheese
        nutrientkg:ingredient_._cottage_cheese
        nutrientkg:ingredient_c._cottage_cheese
        nutrientkg:ingredient_._american_cheese
        nutrientkg:ingredient_c._american_cheese
    }

    # Use AVG to collapse multiple USDA rows into one value per ingredient
    {
        SELECT ?ing1 (AVG(xsd:decimal(?na1)) AS ?avg_na1)
                     (AVG(xsd:decimal(?p1))  AS ?avg_p1)
                     (AVG(xsd:decimal(?k1))  AS ?avg_k1)
        WHERE {
            ?ing1 nkgp:has_usda_entry ?usda1 .
            ?usda1 nkgp:sodium_mg     ?na1 .
            ?usda1 nkgp:phosphorus_mg ?p1 .
            ?usda1 nkgp:potassium_mg  ?k1 .
        } GROUP BY ?ing1
    }

    {
        SELECT ?ing2 (AVG(xsd:decimal(?na2)) AS ?avg_na2)
                     (AVG(xsd:decimal(?p2))  AS ?avg_p2)
                     (AVG(xsd:decimal(?k2))  AS ?avg_k2)
        WHERE {
            ?ing2 nkgp:has_usda_entry ?usda2 .
            ?usda2 nkgp:sodium_mg     ?na2 .
            ?usda2 nkgp:phosphorus_mg ?p2 .
            ?usda2 nkgp:potassium_mg  ?k2 .
        } GROUP BY ?ing2
    }

    nutrientkg:stage_3b nkgp:sodium_threshold_mg     ?na_lim .
    nutrientkg:stage_3b nkgp:phosphorus_threshold_mg ?p_lim .
    nutrientkg:stage_3b nkgp:potassium_threshold_mg  ?k_lim .

    BIND(?avg_na1 + ?avg_na2 AS ?total_sodium)
    BIND(?avg_p1  + ?avg_p2  AS ?total_phosphorus)
    BIND(?avg_k1  + ?avg_k2  AS ?total_potassium)

    FILTER(?total_sodium     <= xsd:decimal(?na_lim))
    FILTER(?total_phosphorus <= xsd:decimal(?p_lim))
    FILTER(?total_potassium  <= xsd:decimal(?k_lim))

    BIND(REPLACE(REPLACE(STR(?ing1),
         "http://nutrientkg.org/entity/ingredient_",""),"_"," ") AS ?ing1_name)
    BIND(REPLACE(REPLACE(STR(?ing2),
         "http://nutrientkg.org/entity/ingredient_",""),"_"," ") AS ?ing2_name)
}
ORDER BY ?total_sodium
